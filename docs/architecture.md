# 架构说明

## 数据流

1. **AkShare** 拉取全 A 日线、财务、资金流
2. **QuantsPlaybook** 提供因子灵感（RSRS、聪明钱等）
3. **factor_score.py** 合成综合分 0~100
4. **RQAlpha / magic-alt/stock** 回测验证信号
5. **daily_stock_analysis** 生成人话报告

## 关键设计

- 因子与回测解耦：因子只输出分数，不直接下单
- A 股规则在回测层强制：T+1、涨跌停、费用
- LLM 只做解读，不做交易决策
- 样本外区间不参与参数优化

## 扩展方向

- 接 QMT 模拟盘
- 接企微/飞书推送
- 加更多研报因子
- 做行业轮动 + 个股精选两层
